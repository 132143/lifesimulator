# 弹窗式文字人生模拟器（Life Simulator）

一款用 **Python 标准库 + Tkinter** 实现的单机文字人生模拟游戏：
所有事件与效果都用**跑团骰子**（d10000 / d100 / d20 / d10 / d6 / d4）判定，无第三方依赖。

> v2 新增：**体质 / 家境随机参数**、**家庭供养系统**、**完整人生阶段流程**（学龄前→…→退休）、
> **一天 8 次操作**、**按月/按年跳过**、**万分位事件概率**（事件不再天天发生）、**名著模组插件架构**。

---

## 一、快速开始（VS Code）

1. **打开文件夹**：VS Code → `文件` → `打开文件夹` → 选择 `D:\desktop\LifeSimulator`。
2. **选择解释器**：按 `Ctrl+Shift+P` → 输入 `Python: Select Interpreter` → 选择任意 Python 3.8+（官方安装包自带 tkinter）。
3. **运行**：打开 `LifeSimulator.py`，按 `F5`，或点右上角 ▶ 运行按钮；
   也可以在终端执行：

   ```bat
   cd /d D:\desktop\LifeSimulator
   python LifeSimulator.py
   ```

4. 弹出的窗口即为游戏主界面（全程只用弹窗交互，无需控制台输入）。

> 目录不存在时程序会自动创建 `D:\desktop\LifeSimulator\`；
> 若该盘不可写，会自动退回到「用户主目录\LifeSimulator」并在界面上提示。

## 二、玩法说明

### 开局
主窗口**底部**就是开局操作区（蓝色边框那一块）：

| 控件 | 说明 |
| --- | --- |
| 姓名输入框 | 直接键入，最多 12 个字，默认「无名氏」 |
| 城市单选 | 哈尔滨（寒冷）/ 北京（温带）/ 上海（亚热带）/ 广州（炎热） |
| ✔ 开始新的人生 | 用输入的姓名与所选城市开始新人生 |
| 读取存档 | 从 `save.json` 继续上一局 |
| 帮助 / 退出游戏 | 查看玩法说明 / 退出 |

城市决定环境气候事件概率与体温波动幅度，**选择后永久生效**。
进入游戏后，底部会切换成游戏菜单（推进一天、跳过这一天、6 种操作、时间跳跃、状态、治病、日志、保存进度、读取进度、保存并退出、帮助）。

### 开局两个随机固定参数（正态分布，永久生效）

| 参数 | 分布 | 作用 |
| --- | --- | --- |
| **体质** | 正态 μ=50、σ=13 | 决定患病判定的容易程度与病程长短 |
| **家境** | 正态 μ=45、σ=16 | 决定父母每月能提供多少供养 |

**体质档位与概率**（正态分布保证"极强/极弱"都很罕见）：

| 体质 | 档位 | 出现概率 | 患病易感倍率 | 婴幼儿期预计生病 |
| --- | --- | --- | --- | --- |
| ≥90 | 铁打之躯 | 0.11% | 0.35 倍 | 约 1.1 次/年 |
| 80~89 | 强健 | 0.94% | 0.45 倍 | 约 1.5 次/年 |
| 60~79 | 较好 | 21.1% | 0.55~0.8 倍 | 约 1.8~2.6 次/年 |
| 40~59 | 普通 | 55.9% | 0.9~1.1 倍 | 约 2.9~3.1 次/年 |
| 20~39 | 偏弱 | 20.9% | 1.2~1.4 倍 | 约 3.5~4.0 次/年 |
| 10~19 | 弱 | 0.95% | 1.55 倍 | 约 5.0 次/年 |
| <10 | 病秧子 | 0.09% | 1.6~2.7 倍 | 约 5.5 次/年 |

**家境档位**（每月供养金额，成年前/大学毕业前由家庭承担）：

| 家境 | 档位 | 每月供养 |
| --- | --- | --- |
| ≥88 | 富裕 | 4200 元 |
| 75~87 | 小康偏上 | 2800 元 |
| 58~74 | 小康 | 1900 元 |
| 42~57 | 普通 | 1300 元 |
| 26~41 | 拮据 | 800 元 |
| 12~25 | 困难 | 450 元 |
| <12 | 贫困 | 200 元 |

### 家庭系统（解决"婴儿不能挣钱却一直欠债"）
* 成年前（幼儿园→高中→大学→读研）的**生活费、学费由父母承担**；
* 月度结算出现赤字时，父母会**垫付**开销（家庭未破产时），因此孩子不会负债累累；
* **家庭破产**：每年生日掷一次万分位判定，默认约 **3‰/年**（家境越差略有提高）；
  破产后父母不再提供任何支持，需要自己想办法 → 这是全游戏最稀有的家庭事件之一。

### 一天 8 次操作（游戏内同一天）
* 每个游戏内的一天有 **8 点行动点**，每次操作消耗 **1 点** → **一天最多 8 次操作**；
* 可做的操作：**休息恢复 / 工作赚钱 / 娱乐消费 / 学习充电 / 社交联络 / 锻炼身体**；
* **操作不推进日期**，同一天可以反复做；同一天重复做同一件事收益递减（85% → 72% → … → 最低 40%）；
* 点「**跳过这一天**」（什么也不做）或「**推进一天**」才结束当天、进入第二天，并重置行动点；
* **一天最多只掷骰触发一次事件**。

### 时间跳跃（按天 / 按月 / 按年）
底部有「时间跳跃」输入框：

* 输入 **月数** → 点「按月跳过」（上限 360 个月）
* 输入 **年数** → 点「按年跳过」（上限 30 年）

跳过期间的处理方式：按天推进日期、逐月结算工资与生活支出（含父母供养）、疾病按天结算、
到年龄节点自动推进人生阶段——**但不生成跳过期间的逐日事件**（只做合理数值汇总，速度快）。

### 事件发生频率（万分之一精度，不再天天有事）
先用 **d10000** 判定"今天是否发生值得记录的事件"（各阶段概率不同），事件日再掷 d100 决定大类、
掷 d10000 抽具体事件。实测：

| 人生阶段 | 事件概率 | 实测有事天数占比 |
| --- | --- | --- |
| 婴幼儿 | 3.00% | ~3% |
| 幼儿园 | 7.00% | ~7% |
| 小学 | 8.00% | ~8% |
| 高中 | 11.0% | ~11% |
| 工作 | 16.0% | 约 17%（实测 2000 天中 344 天） |
| 退休 | 9.00% | ~9% |

另外还有**同类事件冷却**（6 天）与**生病最短间隔**（25 天），避免同类事件刷屏、一个月生好几次病。

### 人生阶段流程（按一般年龄流程设计）
```
婴幼儿(0-2) → 学龄前(3-4) → 幼儿园(5-6) → 小学(7-12) → 初中(13-15)
   → 【中考】→ 高中(17-19) → 【高考】→ 大学(21-24，有概率不上)
   → 读研(25-27，有概率不上) → 工作(22-59) → 退休(60+)
分支：中考失利 → 辍学打工；高考落榜 → 提前工作；考试通过率受「学习充电」积累的学业表现影响
```
实测 40 个样本：上大学 11/40，读研/辍学等分支均会出现，长寿角色 100% 进入退休。

### 事件的现实性约束
| 年龄段 | 可触发的事件 |
| --- | --- |
| 0~3 岁 | 喝奶与辅食、哭闹的夜晚、第一次说话、学步、婴儿发烧护理（不会说话、不能独自出门） |
| 3~6 岁 | 幼儿园第一天、被安排做家务、全家出游 |
| 6~12 岁 | 写不完的作业、零花钱、挑食、校园摩擦 |
| 12~18 岁 | 重要考试、青春社交（不含婚恋） |
| 16 岁以上 | 才可能出现恋爱/分手类事件 |
| 18 岁以上 | 才可能出现求职/职场类事件 |
| 22 岁以上 | 才可能出现结婚、生育事件 |

* **幼年"出门/通勤"类事件必须由父母带领**（事件带 `with_parents` 标记才会对 <6 岁开放）；
* 未成年人收入由家长代管（按年龄折算 15%~60%），不会出现"幼儿中巨奖"的数值崩坏。

### 四项核心属性
| 属性 | 初始值 | 范围 | 说明 |
| --- | --- | --- | --- |
| 健康 | 100 | 0 ~ 100 | 归零即死亡；45 岁后上限随年龄缓降 |
| 幸福 | 50 | 0 ~ 100 | 长期低于 20 会持续扣健康 |
| 金钱 | 1000 | 无上下限，可负债 | 用于治病、消费、娱乐 |
| 体温 | 36.5 ℃ | 正常 36.0 ~ 37.0 | 过高/过低每日扣健康 |

### 疾病（U 型患病曲线 + 体质 + 间隔）
患病概率随年龄呈 **U 型**（体质 50 分的普通人）：

| 年龄段 | 预计生病次数/年 | 年龄段 | 预计生病次数/年 |
| --- | --- | --- | --- |
| 0~2 岁 | 3.2~3.6 | 45 岁 | 1.4 |
| 6 岁 | 2.5 | 55 岁 | 2.0 |
| 12 岁 | 1.5 | 65 岁 | 2.8 |
| **18~25 岁（最低谷）** | 0.9~1.0 | 75 岁 | 4.0 |
| 35 岁 | 1.0 | 85 岁 | 5.4 |

再乘以**体质易感倍率**（0.35~2.7 倍）。同时有 **25 天最短生病间隔**：
实测幼儿相邻两次生病间隔最小 124 天、平均 388 天，约 1 次/年，彻底告别"一个月生好几次病"。

### 寿命模型（平均 80 岁）
自然死亡率采用分段 Gompertz 曲线，45 岁起每年掷一次「寿命骰」，85 岁后加速上升。
多种子实验（60 样本，理性玩家）：**平均 81.5 岁、中位 83.5 岁**，多数落在 70~95 岁。

### 骰子与隐藏剧情
`d10000` 判定事件发生与抽取，`d100` 判定大类与考试，`d4/d6/d10/d20` 判定效果强度。
掷出 **100 / 99 / 2 / 1** 等极端点数会触发隐藏特殊剧情。

### 保存与退出
* 菜单「保存进度」或快捷键 **Ctrl+S**；「保存并退出」或 **Ctrl+Q**；
* 点窗口 **×** 会先询问「保存并退出 / 直接退出 / 取消」；
* 每天结束**自动存档**；死亡总结面板也有「保存并退出」。

## 三、打包分享给朋友（解压即玩、存档同文件夹）

游戏内置**便携模式**：只要程序目录里有 `portable.txt`（或 `save\` 目录、或 `启动游戏.bat` 等分发标志文件），
存档就会写进**程序同目录的 `save\`** 里，整个文件夹可以随意拷贝 / 发人 / 放 U 盘。

一条命令打包：

```bat
python dev_tools\package_release.py
→ release\LifeSimulator_v3.0_便携版.zip      （约 126 KB）

python dev_tools\package_release.py --with-source
→ release\LifeSimulator_v3.0_含源码.zip      （约 275 KB，附带模块化源码与测试）
```

**压缩包内容（玩家版 10 个条目）**

| 包内路径 | 作用 |
| --- | --- |
| `LifeSimulator.py` | 游戏本体（单文件，约 400 KB） |
| `启动游戏.bat` | 双击即玩：自动找 Python、自动建 `save\`、传 `--portable` |
| `portable.txt` | 便携模式标记（存档放同目录） |
| `使用说明.txt` | 给朋友的说明（启动方式、没 Python 怎么办、存档在哪） |
| `README.md` / `docs\*.md` | 完整文档与模组/打包指南 |
| `save\`、`save\mods\` | 空目录：存档与模组位置 |

**朋友的体验**：解压 → 双击 `启动游戏.bat` → 玩 → 存档自动出现在 `save\`。
只需要装一次 Python（不用 pip 装任何东西）。

详细说明见 [`docs\打包与分发指南.md`](docs/打包与分发指南.md)（含免安装 exe 打包方法、发布自检清单、常见问题）。

## 四、模组系统（名著模组 / 插件）

游戏内置插件架构，可以把人生放进完全不同的世界（例如模拟某本名著里的人物一生）。

### 快速开始

```bat
:: 1) 生成模组模板（会在数据目录下创建 mods\my_novel.py）
python LifeSimulator.py --make-mod my_novel

:: 2) 编辑 mods\my_novel.py，填写你的世界

:: 3) 直接启动游戏，会自动加载 mods 目录下的所有模组
python LifeSimulator.py
```

模组目录也可以用环境变量指定（多个目录用 `;` 分隔）：

```bat
set LIFESIM_MODS=D:\我的模组
python LifeSimulator.py
```

### 模组能改什么
| 钩子 | 作用 |
| --- | --- |
| `register_environments()` | 新增"环境/场景"（会加入开局可选地点与气候体系） |
| `register_events()` | 新增事件（进入事件库参与每日抽签，万分位权重） |
| `register_stages()` | 新增人生阶段（进入阶段流程） |
| `daily_event_hook()` | 接管每日事件生成 |
| `on_day_end()` | 每天结束时的额外处理 |
| `opening_text()` | 开局介绍文本 |

模组文件里可以直接使用 `LifeMod` / `register_mod` / `EVENTS` / `CITIES` / `DISEASES` 等符号
（主程序会把它们注入模组命名空间），也可以 `from LifeSimulator import LifeMod`。
详见 `docs\模组开发指南.md`。

## 六、命令参数

```bat
python LifeSimulator.py                          :: 启动图形界面
python LifeSimulator.py --selftest               :: 无界面自检
python LifeSimulator.py --make-mod <模组id>      :: 生成模组模板
python LifeSimulator.py --base-dir D:\some\dir   :: 指定数据目录
python LifeSimulator.py --portable               :: 强制便携模式（存档放程序同目录）
python LifeSimulator.py --no-portable            :: 强制默认模式（用 D:\desktop\LifeSimulator）
```

## 七、健壮性说明

* 路径不存在会自动创建；盘符不可写会自动切到备用目录并在界面提示。
* 存档损坏 / 缺字段 / 旧版本存档：自动补齐新字段（体质、家境、阶段、行动点等），不崩溃。
* 金钱不足时选择付费选项：禁用并提示，或自动降级为可负担的方案。
* 所有属性变更统一做边界约束（健康 0~100、幸福 0~100、体温 30~44 ℃）。
* 时间跳跃输入非数字/超上限：给出友好提示并自动按上限处理。
* 全局异常捕获：任何异常都会以弹窗形式告知，界面不会闪退。
