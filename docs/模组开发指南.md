# 模组开发指南（名著模组 / 插件系统）

本游戏内置插件架构，可以把「人生」放进完全不同的世界——
例如模拟某本名著里某个人物的一生：换掉环境（场景）、换掉事件库、换掉人生阶段流程。

---

## 一、三分钟上手

```bat
:: 1) 生成模组模板（在数据目录的 mods\ 下创建 my_novel.py）
python LifeSimulator.py --make-mod my_novel

:: 2) 用 VS Code 打开 mods\my_novel.py，按下面的说明填写你的世界

:: 3) 启动游戏，模组会被自动加载（控制台会打印加载结果）
python LifeSimulator.py
```

自定义模组目录（可多个，用 `;` 分隔）：

```bat
set LIFESIM_MODS=D:\我的模组;E:\共享模组
python LifeSimulator.py
```

## 二、模组类接口

继承 `LifeMod` 并实现需要的钩子：

```python
class MyNovelMod(LifeMod):
    mod_id = "my_novel"          # 唯一 id
    mod_name = "我的名著模组"     # 显示名
    mod_desc = "一句话说明"
    author = "你的名字"

    def register_environments(self): ...   # 新增环境/场景
    def register_events(self): ...         # 新增事件
    def register_stages(self): ...         # 新增人生阶段
    def daily_event_hook(self, player, dice): ...   # 接管每日事件
    def on_day_end(self, player, report): ...       # 每天结束的额外处理
    def opening_text(self, player): ...             # 开局介绍文本
```

模组文件里可以直接使用这些符号（主程序会注入到模组命名空间）：

`LifeMod`、`register_mod`、`register_event`、`EVENTS`、`EVENT_ORDER`、`CITIES`、`CITY_ORDER`、
`DISEASES`、`LIFE_STAGES`、`STAGE_BY_ID`、`MOD_REGISTRY`、`CATEGORY_BANDS`、
`TRUE_TONE_COLORS`、`ACTION_POINTS_PER_DAY`、`ACTION_COST`、`ACTION_LABELS`

也可以写成显式导入（主程序已把自身注册为 `LifeSimulator` 模块）：

```python
from LifeSimulator import LifeMod, EVENTS
```

## 三、新增环境（场景）

环境会被加入**开局可选地点**，并参与气候、体温、消费、疾病易感计算。

```python
def register_environments(self):
    return {
        "jiaxue_world": {
            "name": "大观园",
            "tag": "虚构",
            "desc": "亭台楼阁、四季分明，园中人多病弱。",
            "seasons": {1: 12.0, 2: 26.0, 3: 16.0, 4: 0.0},   # 四季基准气温
            "variance": 4.0,        # 每日气温波动幅度
            "temp_swing": 1.0,      # 环境事件对体温的影响倍率
            "cost_factor": 1.2,     # 消费水平系数（影响每月支出）
            "env_weights": {        # 四季环境事件权重表
                1: {"rain": 12, "haze": 6},
                2: {"heat_wave": 10, "rain": 14},
                3: {"rain": 10, "cold_wave": 6},
                4: {"cold_wave": 14, "blizzard": 8},
            },
            "disease_weights": {"cold": 18, "gastro": 14, "pneumonia": 10,
                                "chronic": 12, "frostbite": 6, "heatstroke": 4},
        }
    }
```

## 四、新增事件

事件权重使用**万分之一**精度（`weight` 相对于同类候选事件的总权重）。

```python
def register_events(self):
    return [{
        "id": "jiaxue_event_1",
        "name": "葬花",
        "category": "情感",        # 日常/疾病/工作/情感/环境/意外
        "weight": 900,
        "descs": ["你在园中葬花，忽然悲从中来。"],
        "cond": lambda p: p.age >= 12 and p.stage in ("primary", "middle", "high"),
        "tone": "neutral",          # good/bad/neutral/secret
        "special": False,
        "tags": [],                 # 可选："school"/"work"/"outdoor"/"commute"/"disease"
        "choices": [{
            "label": "独自垂泪",
            "hint": "情绪低落",
            "roll": "d10",          # 结果判定骰
            "outcomes": [
                {"range": (1, 5), "desc": "你哭了一场，心里更闷了。",
                 "effects": {"happy": -6}, "tone": "bad"},
                {"range": (6, 10), "desc": "你把心事写进诗里，反而轻松了。",
                 "effects": {"happy": 4}, "tone": "good"},
            ],
            "need_money": 0,
            "need_disease": False,
        }],
    }]
```

### 支持的效果字段（`effects`）
| 字段 | 含义 |
| --- | --- |
| `health` / `happy` / `money` / `temp` | 直接增减（自动做边界约束） |
| `health_boost` / `happy_boost` | 有上限的回复（不超过 100） |
| `cure` | `True` 或疾病 id：立刻治愈 |
| `disease` | 疾病 id：按**体质+年龄 U 型曲线**判定是否真的病倒 |
| `force_disease` | `True` 时跳过判定直接患病 |
| `worsen_disease` | 让已有疾病恶化 |
| `temp_drift` | 跨天持续的体温趋势 |
| `func` | 自定义回调 `func(player) -> [说明文本]`（用于婚姻、生育、失业等状态变更） |

### 连锁事件
```python
{"range": (1, 2), "desc": "病情加重……",
 "effects": {"func": _apply_disease_definite("pneumonia", 1.3)},
 "next_event": "illness_cold_worse"}      # 结算后立即弹出后续事件
```

## 五、新增人生阶段

```python
def register_stages(self):
    return [{
        "id": "jiaxue_stage",
        "name": "入园",
        "start": 12, "end": 17,
        "next": "work",             # 到达 end 年龄后进入的阶段
        "chance_key": "high",        # 事件概率档（见 EVENT_CHANCE_D10000）
        "desc": "你被送进园中，从此与众姐妹同住。",
        "branch": True,              # 是否为分支阶段（不参与标准年龄流程）
    }]
```

可用的 `chance_key`：`infant / preschool / kindergarten / primary / middle /
high / university / postgrad / work / retired / unknown`

## 六、接管每日事件（进阶）

```python
def daily_event_hook(self, player, dice):
    """返回事件字典则优先使用；返回 None 走普通抽签。"""
    if player.age == 15 and player.total_days % 360 == 100:
        return EVENTS["secret_special_100"]
    return None

def on_day_end(self, player, report):
    """每天结束时的额外处理，例如模组专属的持续效果。"""
    if player.money < 0:
        report.add_line("【模组】债主上门催债了。")
        player.apply_effects({"happy": -3})
```

## 七、调试建议

1. **先跑自检**：`python LifeSimulator.py --selftest`（会校验事件结构、边界、存档）
2. **看控制台**：启动时会打印每个模组的加载结果与新增数量
3. **单独验证事件**：在模组目录里写个小脚本：

```python
import importlib.util, sys
spec = importlib.util.spec_from_file_location("LifeSimulator", r"LifeSimulator.py")
ls = importlib.util.module_from_spec(spec); spec.loader.exec_module(ls)
ls.__LIFESIM_BASE_DIR__ = r"."
print(ls.discover_mods())                 # 加载模组
print([k for k in ls.EVENT_ORDER if k.startswith("jiaxue")])   # 检查事件是否进库
print(ls.CITY_ORDER)                      # 检查环境是否加入可选地点
```

4. **事件写错了不会崩溃**：加载失败或条件异常只会在控制台提示，游戏继续运行。
