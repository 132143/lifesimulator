========================================================
        弹窗式文字人生模拟器  Life Simulator
========================================================

【怎么开始玩】
  1. 双击本文件夹里的「启动游戏.bat」
  2. 弹出的窗口就是游戏，输入名字、选一个城市，点「开始新的人生」
  3. 想退出时点「保存并退出」，或直接关窗口（会提示是否保存）

【如果提示没有找到 Python】
  需要先装一次 Python（免费，约 30 秒）：
    1) 打开 https://www.python.org/downloads/  点黄色大按钮下载
    2) 运行安装包时，务必勾选下面两项：
         [x] Add Python to PATH      ← 一定要勾
         [x] tcl/tk and IDLE         ← 游戏界面需要它
    3) 装完后重新双击「启动游戏.bat」即可

  （游戏本身只用 Python 自带功能，不需要 pip 安装任何东西）


【存档在哪？能带走吗？】
  存档就在本文件夹的 save 文件夹里：
      save\save.json        ← 你的进度
      save\life_log.txt     ← 你这一生的人生日志
      save\mods\            ← 想加模组就放这里

  整个文件夹可以随便拷贝 / 发给别人：
    * 拷贝到 U 盘带去别的电脑，存档跟着走
    * 复制整个文件夹就是备份，不会覆盖你朋友的存档
    * 想换电脑继续玩：把整个文件夹拷过去，双击启动游戏.bat，点「读取存档」


【基本玩法】
  * 每个游戏内的一天可以操作 8 次：休息 / 工作 / 娱乐 / 学习 / 社交 / 锻炼 / 夫妻亲密 / 陪伴孩子
  * 点「推进一天」掷骰抽事件；不想做事就点「跳过这一天」
  * 累了可以「按月跳过」「按年跳过」（会做合理的数值结算，不生成逐日事件）
  * 四项属性：健康（归零就死）/ 幸福（长期低于 20 掉健康）/ 金钱（可负债）/ 体温（偏离 36~37 会掉血）
  * 开局会随机给你「体质」和「家境」：
      体质好的人很少生病，体质差的人小病不断
      家境决定父母在你成年前能给你多少生活费（家庭破产后就要靠自己了）
  * 人生流程：婴幼儿 → 学龄前 → 幼儿园 → 小学 → 初中 → 中考 → 高中 → 高考
              → 大学（有概率考不上）→ 读研（有概率考不上）→ 工作 → 退休
  * 结婚后可以「夫妻亲密」：提升幸福度，也可能怀上孩子（记得选避孕方式）
  * 共收录 36 种常见疾病，按年龄和季节发生；寿命一般在 80 岁上下


【界面说明】
  * 底部第一行：「推进一天」「跳过这一天」，右边显示今天还剩几点行动点
  * 底部第二行：8 个当日操作按钮
  * 底部第三行：按月 / 按年时间跳跃（填数字再点按钮）
  * 底部第四行：状态 / 治病 / 日志 / 保存进度 / 读取进度 / 保存并退出 / 帮助
  * 快捷键：Ctrl+S 保存进度，Ctrl+Q 保存并退出，Esc 关闭当前弹窗


【常见问题】
  Q: 双击 bat 一闪而过？
  A: 说明没装 Python 或没勾 PATH。按上面「如果提示没有找到 Python」装一次即可。

  Q: 换台电脑还能读档吗？
  A: 能。把整个文件夹拷过去，双击启动游戏.bat，点「读取进度」。

  Q: 想开两个存档一起玩？
  A: 把整个文件夹复制一份，两份各自有独立的 save 文件夹，互不干扰。

  Q: 想让游戏更好玩 / 加新事件？
  A: 游戏支持「模组」。运行 python LifeSimulator.py --make-mod 我的模组，
     会在 save\mods\ 下生成模板，照着填事件即可（详见 docs\模组开发指南.md）。
